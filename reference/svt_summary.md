# Per-feature node/edge/warning counts.

Accepts an `svt_graph` (returns one row per feature in the default
slice) or an `svt_features` (returns one row per record in that object).
Useful as a fast orientation check.

## Usage

``` r
svt_summary(x)
```

## Arguments

- x:

  An `svt_graph` or `svt_features` object.
